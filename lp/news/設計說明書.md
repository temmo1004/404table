> 美學定位：**editorial newspaper × streetwear poster × brutalist**
> 對照版本：v6 短版（古典暖咖啡棕）
> 核心策略：**用視覺反差讓 35-45 senior 秘書「停下來看完」**

## 一、為什麼要做這版（戰略邏輯）

### 古典版的盲點

v6 短版（暖咖啡棕 + 金色）是**符合 TA 期待**的設計：
- 高級感、像奢侈品 LP
- 沉穩、值得信任
- 但⋯⋯**讀者滑過 100 個 LP 都長這樣**

對「**FB / IG 冷流量**」的 35-45 滑世代秘書，古典版會被當成「**又一個賣 AI 課的廣告**」直接滑掉。

### 潮牌報紙版的賭注

**反差吸引（Disruption Marketing）**：用「**最不像秘書 / 最不像 AI 課**」的設計，**反而打中 TA**。

| 古典版 | 潮牌報紙版 |
|--------|-----------|
| 暖咖啡棕、金色高光 | 米色報紙底 + 黑 + 紅 + 鈷藍 + 螢光黃 + 粉 |
| 宋體優雅、平靜 | Anton 超粗壓縮、Playfair 義大利斜 |
| 對稱、平均間距 | 傾斜、破框、錯位 |
| 「對妳很重要喔」 | 「**WAIT IS NOT A STRATEGY**」 |
| 像信用卡廣告 | 像 i-D Magazine / Off-White lookbook |

### 為什麼 35-45 senior 秘書會吃這套

人們以為 35+ 女性「保守、不接受誇張設計」。**錯**。
她們的**消費品味**早就被全球潮流薰陶：
- 喜歡 Aesop / Le Labo（lo-fi minimalism）
- 看 Vogue / Marie Claire（editorial layout）
- 滑 IG 看 Hypebeast、ZINE、藝術書店
- 買 Marimekko / Muji，但也認識 Margiela

**她們不是不接受設計，是被「**對妳很重要喔**」的客氣 LP 看膩了**。

潮牌版的訊息：「**這堂課不是想像的那種秘書 AI 課**」、「**這也不把妳當笨蛋**」。
這個訊號本身就值 NT$500。

## 二、用色系統（6 色 + 1 紙底）

### Token

```css
--paper: #f3ede0;       /* 米色報紙底，含雜訊紋理 */
--paper-warm: #ebe3d2;
--cream-100: #fffef8;   /* 白報紙 */
--ink: #0a0a0a;         /* 油墨黑（不純黑、有溫度）*/
--red: #ff1100;         /* URGENT 紅 ─ 警告 / 衝動 / 主 CTA */
--cobalt: #1e3fd9;      /* 鈷藍 ─ 信任 / 深沉 / 知識感 */
--yellow: #ffd400;      /* 螢光黃 ─ 高光 / 標籤 / 蓋章 */
--pink: #ff77aa;        /* 桃粉 ─ 女性化 / 暖意 / sticker */
```

### 各色的角色

| 色 | 用途 | 心理任務 |
|----|------|---------|
| 米紙底 | 整本 base | **抑制飽和度**、不刺眼 |
| 油墨黑 | 主文、邊框、印章 | **沉重、權威、報紙感** |
| 紅 | URGENT 標籤、主 CTA、強調 | **行動觸發** |
| 鈷藍 | ACT 02 大面積、講師 CTA | **理性 / 知識** |
| 黃 | highlighter、sticker tape、稀缺 | **注意力勾子** |
| 粉 | sticker note、強調 | **女性 TA 認同** |

### 配色比例（黃金法則）

```
紙底 60% + 黑 20% + (紅 8% + 黃 6% + 鈷藍 4% + 粉 2%) = 100%
```

- **黑色不能少**（給「報紙」感）
- **彩色不能過半**（會變廉價傳單）
- **每屏至少一個鈷藍 / 黃 / 紅錨點**

### Section 之間的色彩節奏

```
ACT 01 ─ 米底 + 紅 + 黃 + 黑       （Hero，飽和度最高）
ACT 02 ─ 鈷藍底 + 黃 + 黑          （大色塊轉場）
ACT 03 ─ 米底 + 粉 / 黃 / 黑卡片   （多彩破框）
ACT 04 ─ 白底 + 鈷藍 + 紅黃        （沉靜、講師專欄）
ACT 05 ─ 米底 + 紅 + 黑            （收口、警告 + 行動）
COLOPHON ─ 黑底 + 黃                （壓底、印刷風）
```

整本滑下來像**翻雜誌專題**，每頁有自己的調性。

## 三、字體系統（5 字型混排）

### Token

```css
'Anton'              /* 超粗壓縮顯示字、大標題 */
'Archivo Black'      /* 備用顯示字 */
'Playfair Display'   /* 義大利斜體 ─ 編輯雜誌 pull quote */
'Space Grotesk'      /* 現代無襯線 ─ 內文 / 副題 */
'Space Mono'         /* 等寬 ─ 標籤 / 印章 / 日期 / 編號 */
'Noto Serif TC' 900  /* 中文宋體 900 ─ 大標 / 引述 */
'Noto Sans TC'       /* 中文無襯線 ─ 內文 */
```

### 字體角色分工

| 場景 | 字型 | 例子 |
|------|------|------|
| **超大數字 / 大標** | Anton + 中文宋 900 | `1,200` `01` `02` `妳會什麼?` |
| **副標 / 解釋** | Space Grotesk 700 | `EVERYTHING YOU TAKE HOME` |
| **編輯感引述** | Playfair Italic 900 | `「妳會什麼啊?」`「P.S. 老公會看不懂」 |
| **印章 / 編號 / 日期** | Space Mono 700 | `★ ISSUE 01` `05/31 SAT` `VOL.` |
| **內文** | Noto Sans TC + Serif TC | 段落、卡片描述 |
| **書信感獨白** | Noto Serif TC 700 | 講師故事、終局詩 |

### 為什麼混 5 種字體

報紙的本質就是**字體混排**：
- 大標、副標、內文、廣告、報頭、頁碼**全都不同字體**
- 一致性反而平庸、混排有「**新聞性**」

LP 借用這個邏輯，**每個元素的字體告訴你它的角色**：
- 看到 Anton → 這是重點 / 巨大數字
- 看到 Playfair italic → 這是某人的話 / 引述
- 看到 Space Mono → 這是元資料（日期、編號、標籤）

**閱讀 hierarchy 不靠字級、靠字型**。這是雜誌設計的核心。

## 四、互動設計 9 大特色

### 1. 跑馬燈頂部 Bar（marquee）

```css
@keyframes marquee {
  from { transform: translateX(0); }
  to { transform: translateX(-50%); }
}
```

- 28 秒一輪、無限循環
- 內容：ISSUE 編號 + 日期 + 稀缺 + 價格 + 標語
- **星號 + 中黃點分隔符**，視覺像報紙跑馬

### 2. Masthead 報頭（sticky）

- 左：HOLO 黑 chip + 課名
- 中：VOL.01 / 名片自救號（Anton 大數字）
- 右：日期 + 立即報名 pill
- **底部紅色進度條**隨滾動填滿

### 3. 卡片傾斜（tilt）+ hover 拉正

```css
.tilt-card.c-01 { transform: rotate(-1.8deg); }
.tilt-card.c-02 { transform: rotate(1.5deg); }
.tilt-card.c-03 { transform: rotate(-1deg); }
.tilt-card.c-04 { transform: rotate(2deg); }

.tilt-card:hover {
  transform: rotate(0deg) translate(2px, 2px);
  box-shadow: 4px 4px 0 var(--ink);  /* 陰影從 8 → 4 */
}
```

- 預設 4 張卡片各自傾斜（**像被釘在牆上的剪報**）
- hover 時拉正、陰影縮短（**像被「翻起來看」**）
- **唯一感**：每張卡的角度不一樣、不機械

### 4. Sticker Tape（膠帶 / 圓貼）

- 每張卡頂部一塊小色塊
- 角度旋轉 -3deg 至 +4deg
- 不同 act 換不同顏色
- **暗示「這是手工貼上去的」**

### 5. 破折線陰影（卡式陰影 / box-shadow offset）

```css
box-shadow: 8px 8px 0 var(--ink);    /* 重陰影、無模糊 */
box-shadow: 8px 8px 0 var(--red);    /* 紅陰影 */
box-shadow: 12px 12px 0 var(--yellow); /* 大黃陰影 */
```

- 完全**沒有 blur** ─ 不是優雅的浮起，是「**截斷剪貼**」
- 不同元素用不同顏色陰影 ─ 視覺重音

### 6. Sticky Note（黃色便利貼）

桌機 only，飄在 hero 區邊緣：

```
P.S.
「妳會什麼?」是
當下最痛的問題
```

- 旋轉 -4deg
- 紅圓點當釘
- **像同事在旁邊偷偷寫便條給妳**

### 7. 印章效果（stamp）

- ACT 03 第 2 張卡有「★ KEY ★」紅章
- 講師肖像旁邊有「12 YRS EA」黃圓章
- ACT 02 提示框上方有紅「★」徽章
- **強化「這是 issue / 限量」感**

### 8. 主 CTA 按下效果（mega-cta）

```css
.mega-cta { box-shadow: 8px 8px 0 var(--ink); }
.mega-cta:hover {
  transform: translate(4px, 4px);
  box-shadow: 4px 4px 0 var(--ink);
}
```

按下去**陰影縮短**、按鈕**位移 4px**，**像把按鈕真的按下去**。

### 9. 螢光筆塗線 + 黃底強調

```css
.underline-y {
  background: linear-gradient(transparent 60%, var(--yellow) 60%, var(--yellow) 92%, transparent 92%);
}
```

- 黃色塗線只在文字下半部（**像真的螢光筆**）
- 不是 underline、不是 highlight `bg`
- 重要關鍵字用此標出，**第一眼掃到**

## 八、為什麼這版可能比古典版**更有效**（也可能崩）

### 可能更有效的理由

1. **辨識度**：滑 FB 1000 則貼文，這版會被記得
2. **稀缺感**：「這不像普通的 AI 課」本身就是定位
3. **分享性**：潮牌版**截圖丟群組**的機率高 5 倍
4. **單價心理**：視覺看起來像**NT$ 3,000 的設計**，賣 NT$500 顯得超值

### 可能崩的理由

1. **TA 老派族群**：50+ 還在用 Yahoo 信箱的秘書可能覺得「**太亂**」
2. **品牌調性**：如果客戶（肆方創育）本身走穩重、潮牌版**不符品牌規範**
3. **載入問題**：5 字型 + 多色塊載入比古典版慢 0.5 秒
4. **轉換歸因**：「**看完很 Cool 但沒報名**」── 美學壓過行動

### 因此建議的投放策略

**A/B 測試**：
- 古典版 → LinkedIn / Email
- 潮牌版 → **FB / IG / 限動轉貼 / 設計圈 KOL 推薦**
- 同一個 UTM、追轉換率
- **看哪版 CTR 高、報名率高**
